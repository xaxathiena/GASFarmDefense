# Orb Combat Sample

This is a standalone test bed for the `com.abel.gas` package.

## Features
- **OrbAttributeSet**: Demonstrates how to extend the base `AttributeSet`.
- **Abilities**: Fireball, Poison, Stun, and Haste implementations.
- **Independence**: This sample only depends on the `com.abel.gas` package and `VContainer`.

## How to use
1. Import the sample via Package Manager (if published) or open the scene in `Samples~/OrbCombat/Scenes/`.
2. Ensure VContainer is installed.
3. Play the scene to see the combat interaction.
